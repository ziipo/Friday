# LLM Orchestration

## Definition

The coordination of multiple LLM calls and system components to achieve complex tasks.

## How it works

Uses structured prompts, tool calling, and deterministic logic to guide LLMs through a multi-step workflow.

## Why it matters

Allows building autonomous agents that can handle reasoning-heavy tasks like triage and synthesis.

## Examples

- Friday's Triage and Synthesizer pipeline.
