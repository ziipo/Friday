# Friday

## Overview

A personal three-layer second-brain system designed to autonomously capture, triage, and synthesize digital artifacts into a structured knowledge base.

## Key facts

- Built using Python 3.13.
- Uses Anthropic Claude 3.5 Sonnet for Triage and Synthesis.
- Implements a pipeline: Scribe (capture) -> Triage (scoring) -> Synthesizer (memory).
